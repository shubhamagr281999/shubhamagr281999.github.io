Classical motion planning, implemented and compared

The value here is not any single planner. It is that two of them run the identical world, so you can see exactly where the cheap method stops working.

  • Motion Planning

My part Solo, on a teaching assistant's ROS harness. The simulation scaffolding is the course's; the planners are mine.

Repository

Problem

Implement the classical planners from first principles rather than calling a library, and understand their failure modes by running them.

Approach

Boundary-following, potential fields, and a velocity-obstacle approach for moving obstacles, each on the same simulated robot and world.

Outcome

The head-to-head is the interesting output: boundary following reaches the goal but along a wildly indirect route, while the potential field runs smooth and fast and then stops short, stuck in a local minimum it cannot escape. That is the textbook failure, reproduced on my own robot, which is a different kind of understanding from reading about it.
