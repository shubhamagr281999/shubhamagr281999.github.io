Sampling-based planning for a 2-DoF arm

Planning for an arm means planning in joint space, where obstacles in the world become shapes you have never seen before. This is the project where that stopped being a sentence in a lecture.

  • Motion Planning
  • Simulation

My part Solo.

Repository

Problem

Move a planar two-link arm from one configuration to another without hitting obstacles, which requires searching joint space rather than the workspace the obstacles live in.

Approach

Map the obstacles into configuration space, grow a randomised tree from the start configuration toward sampled targets, and extract a path once the tree reaches the goal region. Simulated with the arm model in Gazebo.

Outcome

It plans and the arm executes. It is a 2-DoF toy by design, there are no timing or success-rate measurements in the repository, and I stopped working on it in 2021. What it gave me was the direct comparison that later made me choose exact decomposition for the coverage project.
