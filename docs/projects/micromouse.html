Micromouse: flood fill in a maze

A micromouse has to solve the maze and then drive it fast, and those two goals want different things from the same robot.

  • Embedded
  • Motion Planning

My part Team entry, built on a competition-supplied simulation template.

Problem

Explore an unknown maze from a corner, discover walls as sensors reach them, and then return to the centre along the shortest route the map allows.

Approach

Flood fill: assign every cell its distance to the goal given the walls known so far, re-run the fill whenever a new wall is discovered, and drive downhill. It is the standard micromouse answer because it gives a correct route from partial knowledge.

Outcome

An entry for the 2021 challenge. The repository is honestly a competition snapshot rather than a finished artefact, which is why there is no code link here.
